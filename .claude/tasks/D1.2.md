# D1.2 Implementation Plan — Per-Material UBO

## Goal
Each `MaterialInstance` owns a private GL UBO bound to `UBO_BINDING_MATERIAL = 1` carrying material flags/colors. `MaterialInstance::bind` uploads dirty CPU shadow then binds the UBO. Shaders read `layout(std140) uniform MaterialData { ... };` via `material_*` prefixed names. Migrates **only safe per-material parameters** (flags, colors, scalars) — shininess, lights and camera stay legacy.

## Goal-state recap
- ~10–15 fewer `setUniform` calls per `MaterialInstance::bind` (~6–9k/frame saved at 605 draws).
- Foundation for F2 (bindless textures) and D3 (JSON material config).

---

## Architectural decisions

### 1. UBO ownership
Each `MaterialInstance` owns one `Manager::MaterialUbo` (RAII, lazy-init like `FrameUbo`). Buffer lives for instance lifetime; `usage = GL_STATIC_DRAW`. `clone()` makes a fresh UBO (per-instance unique data).

### 2. CPU shadow + dirty flag
`MaterialInstance` holds `MaterialDataStd140 cpuShadow` plus `bool dirty = true`. Features mutate via reference passed at bind time (or accessor on instance). `bind()`:
```
if (dirty) { ubo.upload(&cpuShadow, sizeof); dirty = false; }
ubo.bindTo(UBO_BINDING_MATERIAL);
```

### 3. Block layout
```glsl
layout(std140) uniform MaterialData {
    vec3  material_ambientLightColor;     float material_alpha;
    float material_ambientLightColorIntensity;
    int   material_useMaterial;
    int   material_overrideColorMesh;
    int   material_hasAlbedoTexture;
    int   material_normalMapEnabled;
    int   material_specularMapEnabled;
    int   material_pbrEnabled;
    int   material_hasHoleMap;
    int   material_fogEnable;
    int   material_reflectionEnable;
    int   material_rainDropEnable;
    float material_rainSpeed;
    float material_rainDensity;
    vec4  material_clipPlane;
    vec2  material_uvScale;               vec2 material_uvOffset;
};
```
C++ struct `MaterialDataStd140` mirrors with explicit padding + `static_assert(sizeof(MaterialDataStd140) == X)`.

### 4. What stays legacy
- `material.shininess` — Mesa `pow(x,0)` quirk
- Directional / point / spot lights
- Camera (view/proj/viewPos/uTime)
- IBL gate
- 2D shaders, respawn.fs, explosion.fs (ShaderMaterial path)
- Particle UBO at binding slot 2 (preserved fix)

### 5. `alpha.glsl` / `fog.glsl` / `reflection.glsl` split
Shared between basic.fs and other shaders (normal_map.fs, shadow_map.fs, 2D). Strategy: keep legacy file, create `*_material.glsl` variant for basic.fs. 2D and shadow shaders unchanged.

## Sub-phases

### D1.2a — Dormant infrastructure (no behaviour change)
- New: `Manager/MaterialUbo.h/cpp`, `examples/snake3/Assets/Shaders/functions/material_data.glsl`
- Include block in basic.vs/fs + lights.glsl; **don't read yet**
- Confirm `setupProgramDefaults` binds `MaterialData` to slot 1
- CMakeLists.txt: add MaterialUbo.cpp
- **Test**: identical visuals, no GL errors. Risk: low.

### D1.2b — Upload + bind (still no shader read)
- MaterialInstance holds `MaterialUbo ubo`, `MaterialDataStd140 cpu`, `bool dirty=true`
- bind() uploads dirty + binds slot 1
- clone() copies cpu, marks dirty
- Defaults match current shader: `alpha=1`, `ambientLightColor=vec3(1)`, `intensity=1`
- **Test**: identical visuals. Risk: low–medium.

### D1.2c — Migrate AlbedoFeature (highest regression risk)
- 6 of 15 savings: alpha, ambientLightColor, intensity, useMaterial, overrideColorMesh, hasAlbedoTexture
- This is the path that killed D1.1c (snake tile spheres)
- AlbedoFeature writes cpu directly via RenderContext extension or MaterialInstance ref
- Shader migration in basic.fs + lights.glsl (partial — only Albedo's flags)
- Split alpha.glsl into legacy + `alpha_material.glsl`
- **Test**: snake tile spheres, snake head, coin, floor, walls — checkpoint. Risk: HIGH.
- **Rollback**: AlbedoFeature only, UBO infra stays.

### D1.2d — Migrate remaining safe features (one substep each)
1. UvTransformFeature (uvScale/uvOffset in basic.vs)
2. NormalMapFeature (normalMapEnabled)
3. SpecularFeature flag (specularMapEnabled — shininess STAYS legacy)
4. PbrFeature flag (pbrEnabled)
5. HoleMapFeature (hasHoleMap)
6. FogFeature (fogEnable — split fog.glsl)
7. PlanarReflectionFeature (reflectionEnable, clipPlane — split reflection.glsl)
8. RainRippleFeature (rainDropEnable, rainSpeed, rainDensity)

Each substep: commit-ready, separately verifiable, separately rollback-able.

### D1.2e — Edge cases & non-MaterialInstance callers
- StandardMesh/AnimationArrayMesh fallback branch: no-op stale calls (location -1)
- DepthMapRenderer, FadeIn/OutUniform: untouched (separate shaders)
- SnakeMeshNode3D explosion/respawn: untouched (ShaderMaterial path)
- 2D nodes (BaseNode2D, LabelNode2D, ImageNode2D): untouched (basic_2d.fs)
- Confirm no stderr spam from setX calls with location -1

### D1.2f — Measure + commit
- Transient setUniform counter in ShaderProgram for measurement (revert after)
- Document new pattern in CLAUDE.md
- Commit message: `[REF] per-material UBO (D1.2)`

```
D1.2a (infra dormant)
  -> D1.2b (upload+bind, shader still legacy)
    -> D1.2c (AlbedoFeature — most regression-prone)
      -> D1.2d.1 UvTransform
        -> D1.2d.2 NormalMap
          -> D1.2d.3 Specular flag
            -> D1.2d.4 Pbr flag
              -> D1.2d.5 HoleMap
                -> D1.2d.6 Fog
                  -> D1.2d.7 PlanarReflection
                    -> D1.2d.8 RainRipple
                      -> D1.2e (edge cases)
                        -> D1.2f (measure + commit)
```

Each step ends in green/identical visuals; user verifies before next.

## Visual regression playbook (D1.2c risk)

If user reports tile spheres broken:
1. Diff std140 layout: dump cpu bytes vs expected. Misaligned int/vec3 is usual suspect.
2. Re-verify `static_assert(sizeof(MaterialDataStd140))` matches GLSL block.
3. Confirm MaterialInstance ctor populates safe defaults.
4. Print on first bind: log `cpu.material_ambientLightColor` + `material_useMaterial` for tile material.
5. Validate `setUniformBlock("MaterialData", 1)` returns valid index.
6. Rollback: AlbedoFeature only. UBO infra stays.
